# P4: 값이 바뀐 기준표로 한 추가 예비 실험

[English](README.md) · [사전 등록](PREREGISTRATION_P4.ko.md) · [결과 요약](results/RESULTS_SUMMARY_ko.md)

> **상태: 예비 실험, 2026-11-26 실행. 실행 묶음과 읽는 규칙은 첫 모델 실행 전에 고정함.** 가상 문서로 한 작고 통제된 확인이며, 연구 계획의 주 가설(검증기 판정을 보상으로 한 학습이 지도학습보다 위험측 통과를 더 줄인다)의 검정이 **아님**. 수치를 인용하기 전에 아래 한계를 읽을 것.

## 질문

| 번호 | 질문 | 모델 |
|---|---|---|
| 0 | 닫힌 책: 문서 없이 국내 기준의 한계값을 아는가 | Qwen3-8B |
| 1 | 기준선: 기준표의 **값이 바뀐** 경우(가상 기준표 TE1, TE2)와 공식 기준표(T0, P3 문항)에서, 추가 학습 없는 모델이 위반 설계를 통과시키는 한계값을 검증기에 넘기는 비율 | Qwen3-8B(V1), Qwen3-4B-Instruct-2507(V1, V2) |
| 2 | **다른** 가상 기준표로 만든 문항의 지도학습(QLoRA)이, 학습에 쓰지 않은 조항 3개를 포함한 처음 보는 기준표에서 위험측 통과를 줄이는가 | Qwen3-4B-Instruct-2507, 시드 3개 |
| 3 | 보상 학습 절차(GRPO, 보상 = 검증기 판정)가 8 GB GPU에서 돌아가는가(효과는 묻지 않음) | Qwen3-4B-Instruct-2507 |

모든 실행의 공통 조건: 4비트 가중치, 탐욕 복호, 가상 기준표와 서식 문장, 「철도의 건설기준에 관한 규정」의 조항 7개(3개는 학습에서 뺌), 노트북 GPU 1개(RTX 4070 Laptop, 8 GB).

## 결과

| 질문 | 결과 |
|---|---|
| 0. 닫힌 책(44문항) | 현행 값 0, 2020년 판의 값 0, 그 밖의 값 44 |

| 2. 지도학습, 새 기준표 | 학습 전 118/972 → 시드 1·2·3: **0·7·11**(읽기: 낮아짐) |

| 2. 지도학습, 공식 기준표 | 학습 전 17/270 → 0·0·8(낮아짐) |
| 3. 보상 학습 절차 | 실행됨: 150단계 중 150단계 완료, 실패 0, 갱신 9번, 단계당 14.7초, 최대 4.6 GB(할당). 150묶음 중 141묶음(94%)에서 답 6개의 보상이 모두 같아 배울 것이 없었음 |

칸의 값은 '위험측 통과 / 정답 조건을 위반하는 설계 후보 수'임. 미리 고정한 읽는 규칙: '낮아짐'은 세 시드 모두 학습 전 모델보다 적고 어느 시드도 오경보+보류율이 높지 않을 때이며, 어느 실행이든 보류가 20%를 넘는 묶음은 '결론 없음'이고, 통계 검정은 하지 않음(시드 3개, 조항 7개). 조항별·문서 종류별 읽기는 결과 요약에 있음.

모든 실행에서 스스로 보류한 답은 0건이며, '보류'는 모두 쓸 수 없는 답이었음.

## 한계

- 연구 계획의 주 가설의 검정이 아니며, 보상 학습은 실행 여부만 확인함.
- 학습한 모델은 Qwen3-4B이며 계획의 8B 모델이 아님.
- 기준표·개정문·경과조치는 가상이고 문서는 짧은 서식 문장이어서 실제 문서보다 쉬움.
- 조항 7개, 그중 3개만 학습에서 뺌: 조항 하나가 결과를 좌우할 수 있음.
- 지도학습의 정답에 보류가 없어 학습한 모델이 보류하지 않게 될 수 있음.
